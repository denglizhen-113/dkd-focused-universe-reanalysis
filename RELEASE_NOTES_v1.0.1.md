# Focused-Universe DKD Transcriptomic Reanalysis (M18) — v1.0.1

This maintenance release makes the document-export workflow self-contained.
The export script now uses the verified manuscript DOCX shipped in `manuscript/`
as its Pandoc reference document, rather than a style template outside the
release package. The analyses, data tables, figures, and scientific results
are unchanged from v1.0.0.
