# Scientific Reports submission check

- Title: 14 words; abstract: ≤200 words; keywords: 6.
- Author, affiliation, correspondence, ORCID: populated from the prior author-approved package; recheck portal spelling.
- Main manuscript: line-numbered DOCX; four figures uploaded separately.
- Statistics: exact P values in source tables; two-sided tests; BH and maxT families stated.
- Data/code: exact M19 archives attached and public tag v1.1.1 cited; no DOI has been assigned.
- Ethics: public de-identified secondary analysis; original-study ethics remain with source studies.
- Funding/competing interests/author contributions/AI assistance: included.
- Human-verification fields still required at portal: institutional correspondence preference and suggested/excluded reviewers if requested.
