# Focused-Universe DKD Transcriptomic Reanalysis (M18) — v1.0.0

This release contains the complete analysis code and processed data tables for the manuscript *Focused-Universe Reanalysis of Complement, Coagulation, and Extracellular-Matrix Transcriptional Programs in Diabetic Kidney Disease*.

Key contents:

- Complete 145-gene REML plus modified Hartung-Knapp analysis.
- Sample-label permutation for pathway testing.
- Donor-disjoint sensitivity analysis.
- Supplementary data tables.
- Figure-generation and document-export scripts.

Input data are public GEO accessions GSE142025, GSE96804, GSE30528, and GSE30529. The recorded analysis environment is Python 3.13.9; see `environment.yml`.
